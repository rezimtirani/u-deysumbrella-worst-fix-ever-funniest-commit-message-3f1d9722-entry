One commit message for a bug fix that made everything worse: the checkout no longer crashes, because the checkout is gone.

> fix: checkout no longer crashes — I deleted the checkout

## How it works

`main.py` (Python 3 standard library only) writes the commit message to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 100 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
